# 极区 phi-rebin（球坐标满极域）

实现：`src/modules/dynamics/mhd/integrator/pole_rebin.h`
（`mhd_rebin_t`），由 `sph_t::intg_flx` 在每个 RK 子步之后调用。
状态：2026-10-17，已实现并验证（见 §5）。

## 1. 动机

球坐标下 φ 方向格宽 ∝ sin θ。θ 铺满 0–π 时，极轴附近最内几行的
φ 格宽趋于零：

1. **CFL**：`dt ∝ r sinθ dφ / v_max`，极行把整步长拖小；
2. **隐式算子**：curl–curl 的方位角耦合系数
   `dt·η·l/(A·dφ)` 在极行爆炸（此前用 J_φ 的 sin²θ taper 压制，
   那是症状级补丁）；
3. **穿越极的边界条件**：`pole_t` 的 (θ, φ) → (−θ, φ+π)
   延拓对轴对称场精确，非轴对称数据需要在极附近做 φ 环平均
   （`pole_emf_k` 已对径向 EMF 做了环平均，但态量本身没有）。

`usr_ext/planet_atm_sph` 之类用 `mesh::rebin_t` 做态量的 φ 群平均；
本实现把它接入 MHD（含面心磁场），并保证 **div B 逐格不变**。

## 2. 算法

对 θ 行 `i1`（距极 `d = i1` 或 `n1−1−i1`），若 `d < pole_rebin_lvl`，
该行把 φ 切成 `N = min(n_φ, 2^(pole_rebin_lvl−d))` 个一组的群
（`mesh::rebin_t::num_rebin`；群自 φ=0 起对齐，尾部不足一组的不动）。
逐群做两件事。

### 2.1 守恒量（`hyd.u`）

群内算术平均（`mesh::ker_pole_rebin`，与原 hydro 机制一致）。

### 2.2 面心磁场（`fld.bf`）—— 保 div 的重建

设 `A_a(i) = geo.surface(i, a)` 为该面的面积。沿 φ 各面的面积与 φ
无关，故：

* **跨 φ 的两族面**（r 面、θ 面）：面积加权平均退化为**算术平均**
  （N 个面同面积）；
* **φ 面**（群内内部面）：不能简单平均，否则散度改变。

记群内逐格的 r+θ 通量差（代码的差分约定：上侧面减下侧面）

    U = [A_r(i0+1)B_r(i0+1) − A_r(i0)B_r(i0)]
      + [A_θ(i1+1)B_θ(i1+1) − A_θ(i1)B_θ(i1)]

平均之后 `U` 在群内为常数。格散度为零要求

    U + A_φ [B_φ(j+1) − B_φ(j)] = 0
    ⇒  B_φ(j+1) = B_φ(j) − U / A_φ

即 φ 通量沿群**每面下降 U**，故 φ 面值是一条以群首面为锚的**线性
斜坡**。群尾面保持原值，并且由 rebin 前的无散恒等式

    Σ_j U_j = F_φ(尾) − F_φ(首)

自动与斜坡一致（不需要额外约束）。因此

* 群首、群尾两个 φ 面**不改**（相邻群共享它们，改动会破坏邻群散度）；
* 群内面按斜坡重建。

对**内部群**（`N < n_φ`），斜坡就是两个真实端面之间的线性插值，无害。

**整环群（`N = n_φ`）是特例，必须用常数而非斜坡**：此时群首与群尾
是**同一个物理面**（周期），斜坡无法闭合；而斜率 `V/A_φ` 中 φ 面面积
`A_φ ≈ r dr dθ` 远小于 r/θ 面面积，场自身的微小散度残差
（`V ≠ 0`）会被放大成 O(1) 的 B_φ 摆动，并**全部堆在缝格**（尾格）。
这正是 sp32 长时运行在 r_out × 极行处爆发的机制（实测：th0 行的
φ 剖面是斜率 0.33、闭合缺口 −2.2 的斜坡，而场本身仅 ~0.1）。
故整环群改为**面积加权平均（= 算术平均）的常数**：

* 周期与无散都满足（无散的空环剖面就是常数，任意常数皆可）；
* 端面不再有跳变，缝格不再承担全部残差；
* 环内环向磁通守恒（面积沿 φ 均匀）。

此时残余的逐格散度就是 rebin **之前**场自身的环平均残差 `V`，
不被放大——这是诚实的下限，真正的修法在散度源（见 §6）。

实现为两个 kernel：`ker_pole_rebin_bf_avg`（r/θ 面群平均）与
`ker_pole_rebin_bf_ramp`（φ 面斜坡）。全部 avg 必须先行（ramp 读邻格
的平均值），故两个 kernel 分两次 launch。

### 2.3 触发条件

仅当 **球坐标** 且 θ 侧是物理边界、**且 θ 面落在轴上**
（`|sin θ_face| < 1e-6`）时启动（`mhd_rebin_t::at_axis`）。
后一条比基类 `at_pole`（θ_face < `pole_rebin_thlim`，默认 0.5 rad）
更严：θ 从 0.2 rad 起、以 `out` 为边界的楔形网格（sp31）并不奇异，
不应被平滑——加上这条判据后 sp31 的轨迹与加入 rebin 之前
**逐位相同**。

## 3. 参数（`[mesh]`）

| 参数 | 默认 | 含义 |
|---|---|---|
| `pole_rebin_lvl` | 6 | 参与群平均的极行数；0 关闭 |
| `pole_rebin_bf` | 1 | 面心场 rebin；0 = 只做守恒量（旧行为） |
| `pole_rebin_threadlim` | 32 | 每块线程数上限（r 方向） |
| `pole_rebin_thlim` | 0.5 | 基类的 θ 阈值（本实现的 `at_axis` 更严，通常无感） |

`N` 随行号对半递减，所以极行是全 φ 平均（轴对称化），逐行放开；
`n_φ` 为 2 的幂时群边界不产生残余。

## 4. 与其它模块的关系

* **隐式 non-ideal**：rebin 在**理想步末尾**执行，随后隐式求解从
  已 rebin 的 `bf` 出发；隐式算子本身保 div B，故两步叠加仍然保 div。
  反过来（先隐式后 rebin）会破坏隐式的守恒输出，不可取。
* **STS / 显式 non-ideal**：同样受益（步长不再被极行拖住）。
* **SMR**：每个块各自 rebin；θ 行号是块局部量，故只在块本身触及
  极轴时生效。

## 5. 验证（sp32 满极域，32×16×8，n_φ=8，CUDA/PRECISION=1，GPU1）

4 个循环后、单块 dump 的离散 div B（`ni_sph21/divb_sph.py`）：

| 配置 | max\|divB\| | 极行（θ 行 0） |
|---|---|---|
| 无 rebin（`lvl=0`） | 5.3e+01 | 5.3e+01 |
| `lvl=3` | 9.0e-02 | 9.3e-03 |
| `lvl=6` | 8.7e-02 | 1.2e-02 |
| `lvl=6` + `pole_rebin_bf=0` | 8.5e+00 | 8.5e+00 |

（末行证明面心场的斜坡重建是必要的：只平均守恒量会让极行 div B
劣化约 700 倍。）

**步长**（同一算例，20 循环）：

| 配置 | dt 轨迹 |
|---|---|
| 无 rebin | 3.19e-3 → 5.1e-4（第 5 循环起塌陷，随后单调下降） |
| `lvl=6` | 3.18e-3 → 3.41e-3（单调上升） |

**长时（修正前后对照，`mg_cc=1`，70 循环）**：

| 配置 | 结果 |
|---|---|
| 斜坡版（整环也用斜坡） | 第 ~11 次 dump 起 B_φ 在 (r≈1.3, θ 行 0–3, φ 缝) 指数增长，第 55 循环 dt 塌陷，第 100 循环 max\|B\|=1.6e4 |
| **整环常数版（当前）** | 70 循环干净，dt 3.18e-3 → 4.13e-3（单调上升），max\|B\|=0.71 |

**机理（实测）**：斜坡版的极行 φ 剖面是一条斜率 0.33、在缝面无法闭合
（缺口 −2.2）的直线，而场本身仅 ~0.1。原因见 §2.2：整环群的斜坡
斜率 `V/A_φ` 把场自身的微小散度残差放大 `N·` 倍并集中到缝格。
整环常数版把 th0–th3 四行恢复为严格平坦的环（dump 实测逐 φ 值
完全相同）。

**长时（纯理想 + rebin，`mg_cc=0`，100 循环）**：`dt` 3.2e-3 →
5.6e-3，`max|B|` = 0.20（有界），`max|divB|` = 1.6e-2
（rms 1.3e-3，边界壳层量级），无 NaN。

## 6. 已知限制

1. **φ 方向跨块的环平均**未实现：块沿 φ 切分时，块边界的群边界
   两侧不一致（与 `pole_emf_k` 的单块限制同源）。满极域生产算例
   目前用单块，或让 φ 切分落在群边界上。
2. **隐式支路的长时不收敛**（与 rebin 无关）：`lvl=6` + `mg_cc=1`
   在本算例继续跑到 t≈0.6 后，隐式求解的每次 pass 相对变化升到
   O(1)，最终动量出现 Inf、dt→0（不再崩溃，但停摆）。判别：

   | 配置 | 结果 |
   |---|---|
   | 纯理想 + rebin | 200 循环到 t=1.37，dt 1e-2，干净 |
   | 隐式 + rebin（lvl=6） | t≈0.68 停摆 |
   | 隐式 + rebin（lvl=3，无内部群） | t≈0.61 停摆 |
   | 隐式 + `mg_cc_bc=0` | 更晚（大 dt 时）NaN |
   | 隐式 + `prof_eta_a = 0.005`（η/10） | 200 循环到 t=1.24，干净 |
   | 隐式 + 单层 MG（`mg_cc_lvl=0`） | t≈0.67，dt 衰减到 1.5e-4 |

   η 减 10 倍即完全消失，故这是**大 ambipolar η 下的隐式求解
   鲁棒性**问题，不是极区/几何问题。空间分布（逐格 `dt·η/dx²`）：

   | 时刻 | 最大刚度 | 位置 |
   |---|---|---|
   | t = 0（seed，η ∝ r⁸） | `dt·η/dr²` = 4.1 | **外边界**，极行 |
   | t ≈ 0.6（风抽空内区，ρ 近均匀） | `dt·η/dr²` = 7.8 | **内壳 r ≈ 0.6–0.8，全部 θ** |
   | 同上 | `dt·η/(r sinθ dφ)²` = 4.3，曲率 `dt·η/(r sinθ)²` = 2.7 | **极列（θ 首/末行）× 内边界** |

   即刚度随时间从外边界迁移到**内边界 × 极列**（`r` 与 `sinθ` 同时最小）。

   失效序列（`print_iter = 1` 可复现）：某步内层 V-cycle 的 defect
   由 1e-4 起每循环 ×1.2 单调上升（迭代矩阵有放大模），随后外层
   每次 pass 的相对变化升到 O(1)，最终动量 Inf。相关防线：
   `[multigrid] iter_guard`（内层单调性回退，实测会触发并回退成功）
   与 Richardson 外层的 `mg_cc_romega` 阻尼/回退。
   **根因推断**（有证据但未最终证实）：隐式支路的 div B 逐步长到
   O(1)（本算例 t=0.6 时 max|divB| ≈ 3；纯理想只 1.6e-2），而
   base 算子与 CT-adjoint 精确算子的差正是 `dt·η·grad(div B)`——
   在 `dt·η/dx² ≈ 8`、`div B ≈ 3` 时该项达 O(10³)，缺陷修正无法
   收敛。逐个排除：`bc = 0` 更晚但 NaN，`bc = 2` 在 t = 0.07 就死，
   单层 MG 只稍慢——三者都不是出路。候选正解：让 bc = 1 的
   band 行闭合（`mg_cc_bclose` 覆写 src，**不是 curl 更新**）
   变成 curl 一致的形式，或在每步后做一次 div B 投影。
3. **bc = 1 的 band 行已改为 curl 一致**（`mg_cc_band` 只标记
   边界法向分量；切向行不再用代数 Newton 闭合），极行的 div B
   从 53 降到 0.81（无 rebin 时）、70 循环时从 1.48 降到 0.48。
   剩余每步泄漏约 1.2e-2，集中在 **r_out 壳层 × 中纬行**，根因是
   **理想侧 `out` 边界与隐式侧 bc = 1（essential）不一致**：隐式
   每步把理想 CT 已推动的边界法向面冻结回去。`bc = 0` 时泄漏小 20 倍，
   但长时求解本身不稳（t ≈ 0.066 即死）；`bc = 2` 在 t ≈ 0.07 死。
   真正的闭合需要两侧都施加 essential 条件（理想侧的边界棱边 EMF
   置零），或放弃边界法向面的冻结。
4. 斜坡重建假设 rebin 前的场是离散无散的（CT 保证）；若从外部读入
   一个不无散的场，斜坡只保证“不再引入新的散度”。
